///1ABOUT
DWED is a real-mode DOS text editor with multiple
files, syntax highlighting, and classic menus.

This maintained fork is being developed into an
EDIT replacement. It is not a BASIC interpreter.

Editor sources are MIT licensed. The linked Free
Pascal runtime has separate license notices and
an independent-module linking exception.
See the distributed licenses directory.

Upstream: https://github.com/DosWorld/dwed/
Maintained fork: https://github.com/ddanila/dwed/

Use Up/Down to choose a topic and Enter to open it.
Use Left/Right to page through the topic text.
Esc returns to the editor.
///1MENUS
~F10~ opens the File menu.
~Alt-F/E/S/O/H~ opens File/Edit/Search/Options/Help.

Use arrows to select a group or command.
~Enter~ runs it. ~Esc~ or ~F10~ cancels the menu.
Highlighted letters select menu commands.

Opening and cancelling a menu preserves selection.
Unavailable Undo, Redo and clipboard commands are
shown disabled.

Use File / New for a new unnamed document.
Use Help / Contents or ~F1~ for this help.
///1SAVING
~F2~ or ~Ctrl-S~ saves the current document.
~Shift-F2~ chooses another name with Save As.
~Ctrl-Shift-S~ saves all open documents.
An unnamed document asks for a name when saved.

The status line's ~*~ marks unsaved changes.
Save, Close and Exit share Save/Discard/Cancel
choices. Read the displayed choices: cancelling
keeps the document open and unsaved.

A failed save retains the unsaved buffer.
On protected media, use Save As to a writable drive.
An existing destination requires replacement
confirmation when choosing a different filename.
///1RECOVERY
After a save error, a recovery screen may list
files or handles whose cleanup remains pending.
~R~ retries cleanup. ~Enter/Esc~ returns to editing.
Leaving with an open handle is blocked.
~K~ can leave retained files when offered on exit.
Up/Down scrolls long paths and messages.

On startup, ~Interrupted save~ offers records in
the current and command-line file directories.
~R~ opens verified contents as an unsaved document.
~S~ skips one record; ~Esc~ skips the remaining ones.
A damaged record or read error offers Retry/Skip.

Recovering does not delete retained files.
Use ~F2~ to save the recovered document explicitly.
At startup, ~C~ checks whether the saved copy is
already installed. After a successful check,
~D~ removes the listed verified recovery files,
including fingerprinted older backups.
~Enter~ or ~Esc~ keeps them. Changed contents and
unverified older backups are left in place.
An already open original remains a separate window.
After saving recovered contents, EDIT verifies
the new saved copy and offers cleanup again.
This also works after further edits or Save As.
Keep leaves the files for inspection; another
save in this session offers the check again.
///1TEXT
Tabs and high-bit codepage bytes are preserved.
Existing CRLF, LF or CR line endings and the final
newline state are preserved when saving.

A physical line can contain at most 255 bytes.
Longer lines, mixed newline styles and unsupported
control bytes are rejected; they are not silently
split, normalized or removed.

File capacity depends on available memory, open
windows and undo history. If a load runs out of
memory, its partial contents are discarded and
existing documents remain available.
///1EDITING
~Enter~ splits the line and copies leading spaces
and tabs from before the cursor. The suffix keeps
all of its bytes; indentation does not trim it.

~Tab~ inserts a literal tab without a selection.
On selected lines, Tab/Shift-Tab indent/unindent.
~Insert~ switches insert and overwrite modes.

~Ctrl-Z~ undoes an edit in DOS memory mode.
~Ctrl-Shift-Z~ redoes it. Each document has its own
history. Saving establishes its clean checkpoint.
Undo history is bounded; older edits can expire.

~Ctrl-Shift-PgUp/PgDn~ moves a line up/down.
///1NAVIGATION
~Arrows~ move the cursor.
~Home/End~ moves to the line's start/end.
~PgUp/PgDn~ moves by a screen page.
~Ctrl-Home/End~ moves to the file's start/end.
~Ctrl-Left/Right~ moves by words.
~Ctrl-L~ goes to a line number.
~Ctrl-O~ opens the Pascal procedure/function list.

Hold Shift with navigation keys to select text.
Tabs occupy their displayed cells while the
selection keeps the original tab bytes.
///1CLIPBOARD
~Ctrl-X/C/V~ cuts, copies or pastes.
~Shift-Delete~ cuts the selection.
~Ctrl-Y~ cuts the current line.
~Ctrl-U~ pastes the clipboard.

~Alt-F2~ saves the clipboard to a file.
~Alt-F3~ loads the clipboard from a file.
The clipboard is shared by open documents.

The internal clipboard has a finite capacity.
Oversized or unsupported input is rejected.
A host clipboard may be used when the environment
provides one; interoperability depends on the host.
///1SEARCH
~Ctrl-F~ or ~F7~ opens Find/Replace.
~Ctrl-Shift-F~ uses case-sensitive matching.
~Ctrl-K~ searches or replaces again.

Search and replacement use the combined prompt.
Read its displayed options before confirming.
///1FILES
~F3~ opens a file. A missing name starts a new file.
Other open errors leave existing documents intact.

~Alt-F4~ closes the current document.
~Esc~ exits the editor.
Unsaved documents offer Save/Discard/Cancel.

~F6~ selects the next open document.
~Alt-F6~ opens the window list.
~Alt-F5~ shows the DOS screen.
///1SYNTAX-HL
Syntax highlighting supports assembler, Pascal,
BASIC, C/C++, Sphinx C--, XML/HTML and DOS batches.

Options / Syntax highlighting or ~Ctrl-Alt-H~
chooses the highlighting scheme.

Set ~hl.enable=0~ in DWED.CFG to disable it.
Highlighting does not provide a compiler or runtime.
///1CMD-LINE
Run ~DWED filename~ to open a file.
Several filenames open separate documents.

Configuration overrides use /key=value or
-key=value. For example:

    DWED /tab_size=4 SAMPLE.TXT

The launcher is ~DWED.COM~. Keep ~DWEDOVL.EXE~ and
~DWED.CFG~ beside it. Help is embedded in the overlay.
///1RUN_USR_SHELL
~F5~, ~F8~ and ~F9~ run configured external commands.
Examples in DWED.CFG:

    usr.def.f5 = %COMSPEC%
    usr.def.f8 = make all
    usr.def.f9 = make run

The editor checks unsaved documents and pending
I/O cleanup before handing control to a command.
Recursive editor launches are refused.
///1EXT-MEMORY
~memory=dos~ selects conventional-memory storage.
This is the maintained and tested editing backend.
It provides the integrated undo/redo history.

~memory=swap~ selects the inherited temporary-file
backend. It still needs runtime qualification and
does not provide the same undo integration.

There is no guaranteed multi-gigabyte file limit.
Use the DOS backend for the qualified behavior.
///1CONFIG
DWED.CFG is read from the current directory first,
then from the launcher's directory.
Use one ~key=value~ setting per line.

~tab_size=8~ selects the tab-stop spacing.
Colors use hexadecimal DOS text attributes.
For example, ~color.text=70~ is black text on a
light-gray background: background digit first.

Common settings:
    hl.enable = 1
    memory = dos
    color.text = 07
    color.text_sel = 70
    color.menu = 1b
    color.menu_sel = 30

The supplied DWED.CFG lists the other settings.
